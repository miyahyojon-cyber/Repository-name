# Кубоград — Android-версия

3D-песочница из блоков. Это обычная веб-игра (HTML + CSS + JavaScript, библиотека three.js), упакованная в Android-приложение через Capacitor. Игровой процесс не менялся. Игра сохраняет мир в памяти приложения.

## Что внутри

```
kubograd-android/
├─ www/index.html          игра целиком (HTML, CSS и JavaScript в одном файле)
├─ www/three.min.js        появится после шага «Скачать three.js» (см. ниже)
├─ capacitor.config.json   настройки приложения (имя «Кубоград», id com.kubograd.game)
├─ package.json            зависимости Capacitor
├─ scripts/get-three.js    скачивает three.js, чтобы игра работала без интернета
├─ scripts/patch-android.js  полный экран и «экран не гаснет» (по желанию)
└─ .github/workflows/build-apk.yml  автосборка APK на GitHub
```

Игра написана без React, отдельной сборки (npm build) не требуется.

## Управление (сенсорный экран)

- Левая половина экрана: джойстик (ставишь палец и ведёшь).
- Правая половина: поворот камеры (ведёшь пальцем). Короткий тап: действие предмета в руке (сломать или поставить блок, ударить, выстрелить, съесть).
- Кнопка «ПРЫЖОК»: прыжок и плавание вверх.
- Нижняя панель: 6 быстрых ячеек, нажми на нужную.
- «ИНВ»: инвентарь, броня, крафт 3×3, печь и сундук. Нажми на предмет, затем на ячейку, чтобы переложить.
- «ЧАТ»: команды Verity («за мной», «стой», «ко мне», «танцуй», «атакуй», «найди портал», «где деревня», «где дом»).
- «II»: пауза и выход в меню (мир сохраняется).

## Быстрая проверка в браузере (без Android)

Открой `www/index.html` в Chrome. Нужен интернет, чтобы подтянулся three.js (если файла `www/three.min.js` ещё нет, игра сама возьмёт его из сети).

## Шаг 0. Скачать three.js (для игры без интернета)

Нужен Node.js 18+ (https://nodejs.org).

```
npm install
npm run get-three
```

Если не получилось, скачай файл вручную: https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
и положи его в `www/three.min.js`.

## Вариант A. Собрать APK только с телефона (через GitHub, без Android Studio)

1. Зарегистрируйся на https://github.com и создай новый пустой репозиторий (имя любое, ветка `main`).
2. Распакуй этот ZIP и загрузи ВСЕ файлы и папки в репозиторий («Add file → Upload files»). Важно, чтобы папка `.github` загрузилась тоже. Если телефон не загружает скрытые папки, создай файл `.github/workflows/build-apk.yml` вручную в веб-редакторе GitHub и вставь содержимое из этого архива.
3. Открой вкладку **Actions**, выбери **Build APK**, нажми **Run workflow**.
4. Через 5–10 минут открой готовый запуск, внизу в разделе **Artifacts** скачай `kubograd-debug-apk` (внутри `app-debug.apk`).
5. Установи APK на телефон (см. раздел «Установка»).

## Вариант B. Собрать на компьютере (Android Studio)

Нужны: Node.js 18+, Java 17 (JDK), Android Studio (с Android SDK).

```
npm install
npm run get-three
npm run android:add
npm run android:sync
npm run android:open
```

Откроется Android Studio. Подожди, пока закончится синхронизация Gradle, затем:
**Build → Build Bundle(s) / APK(s) → Build APK(s)**.
Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

Либо без Android Studio, из терминала (после `npm run android:add`):

```
npm run android:sync
npm run apk
```

## Установка APK на телефон

1. Скопируй `app-debug.apk` на телефон и открой его.
2. Разреши установку из этого источника («Неизвестные приложения»), если телефон спросит.
3. Запусти «Кубоград».

## Обновление игры

Измени `www/index.html`, выполни `npm run android:sync` и собери APK заново.

## Важное

- Это «debug»-APK: для личного использования подходит. Для публикации в Google Play нужен подписанный релиз (Android Studio: Build → Generate Signed Bundle / APK) и аккаунт разработчика (разовый взнос $25).
- Версии Capacitor в `package.json` указаны `^6`, это требует Java 17. Если ставишь новее, смотри требования на https://capacitorjs.com/docs.
- Шрифт заголовков (пиксельный) подтягивается из интернета. Без сети используется обычный моноширинный шрифт, игра работает так же.
- Мир хранится в памяти приложения. Если очистить данные приложения, сохранение пропадёт.
- В игре есть авторские рисунки блоков, мобов и построек, созданные в коде. Знаков и материалов Minecraft внутри нет.
